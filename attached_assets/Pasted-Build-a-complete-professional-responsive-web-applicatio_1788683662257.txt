Build a complete, professional, responsive web application prototype for Smart India Hackathon 2026 problem statement SIH26174:

“AI Human Activity Recognition for On-board BAS Experiments”

The website is an interactive prototype/demo of an AI-powered on-board experiment assistant for astronauts/crew members.

IMPORTANT:
This is NOT a generic AI landing page.
It should look like a real aerospace/mission-control software interface combined with a modern AI computer-vision dashboard.

The application must be visually impressive enough for a Smart India Hackathon judging/demo environment.

==================================================
1. CORE PRODUCT CONCEPT
==================================================

The system monitors an experiment using a camera/video feed and uses AI-based human activity recognition to determine:

• What the crew member is doing
• Which equipment/object is being interacted with
• Whether the current action is correct
• Whether the prescribed experiment sequence is being followed
• Whether a step has been skipped
• Whether an action is out of sequence
• What the next expected step is
• When an experiment is complete

The system should provide:

CAMERA
↓
PERSON DETECTION
↓
POSE ESTIMATION
↓
OBJECT DETECTION
↓
HAND–OBJECT INTERACTION
↓
ACTIVITY RECOGNITION
↓
TEMPORAL / SEQUENCE ANALYSIS
↓
EXPERIMENT STATE MACHINE
↓
GUIDANCE + ALERTS + LOGGING

The website should visually communicate this entire pipeline.

Camera observes crew.

Recognizes person, pose, objects and activity.

WHAT MAKES THE SOLUTION UNIQUE?

It understands the experiment sequence.

WHAT HAPPENS IF SOMETHING GOES WRONG?

The system detects the violation and gives immediate guidance.

WHY IS IT USEFUL?

It provides local/on-board assistance, reduces dependence on continuous ground support, and creates structured experiment logs.
